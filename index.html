المقدمة عرض الموضوع مقارنة المراجع

أولاً: المقدمة والتعريف

المواقع في الماضي كانت ثابتة، والمستخدم يدخل ليقرأ ويمشي. لكن مع ظهور JavaScript سنة 1995 بواسطة Brendan Eich، أصبحت المواقع تتفاعل مع ضغطات المستخدم لحظياً دون الحاجة إلى تحميل الصفحة من جديد.

ما هي JavaScript؟

هي لغة برمجة تعمل داخل المتصفح، ومسؤولة عن التفاعل مع المستخدم. فمثلاً عند الضغط على زر إعجاب، أو فتح قائمة، أو ظهور رسالة، تكون JavaScript هي التي تنفذ هذا التفاعل.

معلومة مهمة: تعمل HTML على بناء هيكل الصفحة، وCSS على تنسيق الشكل والألوان، بينما تضيف JavaScript التفاعل والحركة.

ثانياً: كيف تعمل مع ضغطات المستخدم؟

تعتمد JavaScript على ما يسمى الأحداث (Events)؛ وهي أفعال يقوم بها المستخدم مثل الضغط على زر أو الكتابة أو تحريك الماوس.

خطوات تنفيذ الحدث

  1. الحدث (Event): يضغط المستخدم على زر أو يقوم بحركة ما.
  2. مستمع الحدث (Event Listener): يراقب العنصر وينتظر حدوث الفعل المطلوب.
  3. المعالج (Handler): ينفذ الأمر المحدد عند وقوع الحدث.
  4. تعديل DOM: تتغير محتويات الصفحة أو شكلها دون إعادة تحميلها بالكامل.

أمثلة عملية

  • إظهار نافذة منبثقة (Modal) عند الضغط.
  • التحقق من صحة الإيميل قبل الإرسال.
  • تغيير لون زر بعد الضغط عليه.
  • فتح قائمة منسدلة (Dropdown Menu).

مثال كود بسيط

const btn = document.getElementById('myBtn');

btn.addEventListener('click', () => {
  alert('تم الضغط!');
});

في هذا المثال، عند الضغط على الزر الذي يحمل المعرّف myBtn تظهر رسالة تنبيه مكتوب فيها «تم الضغط!».

ثالثاً: مقارنة بين HTML وCSS وJavaScript

تعمل اللغات الثلاث معاً لتكوين موقع ويب متكامل، ولكل لغة وظيفة مختلفة:

اللغةوظيفتها الأساسيةمثال
HTMLبناء هيكل ومحتوى الصفحةعنوان أو فقرة أو صورة
CSSتنسيق الشكل والألوانتغيير لون العنوان وحجم الخط
JavaScriptإضافة التفاعل والحركةزر يعرض رسالة عند الضغط

رابعاً: المميزات والعيوب والخاتمة

المميزات

  • تفاعل فوري بدون تحميل الصفحة.
  • تحسين تجربة المستخدم (UX).
  • تعمل على معظم المتصفحات والهواتف.
  • توجد مكتبات وأطر عمل جاهزة مثل React وVue تسهّل العمل.

العيوب

  • لو المستخدم قفل JavaScript، بعض وظائف الموقع قد لا تعمل بشكل صحيح.
  • قد تسبب بطئاً إذا كان الكود كبيراً أو غير منظم.

الخاتمة

حولت JavaScript الويب من صفحات ثابتة إلى تطبيقات تفاعلية مثل فيسبوك ويوتيوب. وفهم طريقة عمل الأحداث وDOM هو أساس مهم لتطوير ويب ناجح.
